## 十五、后续建议

1. **确保 API Key 配置**: Chat 模块的 SSE 流式功能运行前，需在管理后台配置至少一个有效的 LLM API Key。
2. **实现 uptime 记录**: 可在 app.py 的 lifespan 启动时记录 `start_time`，用于计算精确的 uptime。
3. **模型字段优化**: SentimentDashboard 模型的 `top_words_json` 和 `top_events_json` 存储为 JSON 字符串，前端可能需要解析。后续可考虑改为 JSON 字段类型。
4. **建立接口回归检查机制**: 每次新增/修改接口时同步更新文档，避免文档与代码持续偏离。
